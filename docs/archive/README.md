for provenance rather than deleted.

  `documentation-validation.md` — notes from earlier repository-cleanup passes.
  They describe process, not the software, so they are archived out of `docs/`.
- `README.previous.md` — the previous `README.md`, kept as a reference point
  before the current rewrite.
- `icloud-conflict-copies/` — macOS iCloud conflict duplicates (`* 2.json`,
  `* 2.log`, `* 2.jsonl`) that had appeared under `artifacts/`. They are
  divergent sync copies of real run outputs, moved here rather than deleted so
  nothing is lost; the authoritative outputs remain under `artifacts/`.
